# Кулинарная книга — сервис планирования питания

## Описание проекта

«Кулинарная книга» — веб-приложение на Django для управления блюдами, ингредиентами и приёмами пищи.

Проект помогает пользователям организовывать питание, просматривать блюда, контролировать наличие необходимых ингредиентов и рассчитывать калорийность.

## Целевая аудитория

- Люди, следящие за здоровым питанием;
- Спортсмены и фитнес-энтузиасты;
- Семьи, планирующие питание;
- Пользователи, желающие организовать свою кулинарную книгу.

## Предметная область

Управление процессами организации питания, включая:

- Создание и хранение блюд;
- Учёт ингредиентов и единиц измерения;
- Связь блюд с необходимыми ингредиентами;
- Разделение блюд по приёмам пищи;
- Контроль калорийности;
- Проверку наличия ингредиентов.

## Основные сущности

- **Dish (Блюдо)** — название, калорийность и приём пищи;
- **Ingredient (Ингредиент)** — название продукта и единица измерения;
- **Meal (Приём пищи)** — завтрак, обед или ужин;
- **DishIngredient** — промежуточная модель связи блюд и ингредиентов.

Для связи блюд с ингредиентами используется ManyToManyField с промежуточной моделью DishIngredient.

## Основные функции

### Работа с блюдами

- Просмотр списка блюд;
- Просмотр подробной информации о блюде;
- Поиск блюд по названию без учёта регистра;
- Фильтрация по приёму пищи;
- Фильтрация по максимальной калорийности;
- Сортировка по названию, калорийности и приёму пищи;
- Пагинация списка блюд;
- Создание новых блюд;
- Редактирование существующих блюд.

### Работа с ингредиентами

- Хранение списка ингредиентов;
- Указание единиц измерения;
- Добавление ингредиентов к блюдам;
- Удаление ингредиентов из состава блюда;
- Проверка наличия всех необходимых ингредиентов.

### Работа с калорийностью

- Хранение калорийности блюда;
- Расчёт калорийности одной порции;
- Определение уровня калорийности блюда.

### Дополнительные методы моделей

- `is_available()` — проверка наличия всех ингредиентов;
- `calories_per_portion()` — расчёт калорийности на одну порцию;
- `calorie_level()` — определение уровня калорийности;
- `serving_suggestion()` — получение рекомендации по сервировке;
- `uses_ingredient()` — проверка использования определённого ингредиента.

## Структура проекта

- `dishes/` — приложение для работы с блюдами;
- `ingredients/` — приложение для работы с ингредиентами;
- `meals/` — приложение для работы с приёмами пищи;
- `homepage/` — главная страница проекта;
- `menu/` — настройки проекта и маршрутизация;
- `templates/` — HTML-шаблоны;
- `static_dev/` — статические файлы;
- `db.sqlite3` — база данных SQLite.

## База данных

В проекте используется SQLite.

Основные таблицы:

- `dishes_dish` — блюда;
- `dishes_dishingredient` — связи блюд и ингредиентов;
- `ingredients_ingredient` — ингредиенты;
- `meals_meal` — приёмы пищи.

Для просмотра таблиц и записей можно использовать SQLite Viewer в Visual Studio Code.
