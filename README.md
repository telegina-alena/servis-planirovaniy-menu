# Сервис планирования меню

## Назначение

Помочь пользователям структурировать своё питание, планировать приёмы пищи на каждый день, контролировать наличие ингредиентов и упростить процесс подготовки к приготовлению блюд.

## Целевая аудитория

- Люди, следящие за здоровым питанием  
- Спортсмены и фитнес-энтузиасты  
- Семьи, планирующие недельное меню  

## Предметная область

Управление процессами планирования питания, включая:

- Учёт количества продуктов и их доступности  
- Составление блюд из ингредиентов  

## Основные сущность

- блюдо
- день
- прием пищи
- ингредиент
- калории

## Основные функции
- check_dish_availability
- get_calories_per_portion
- get_serving_suggestion
